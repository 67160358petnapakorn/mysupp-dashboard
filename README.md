# MYSUPP – Personalized Supplement Planning Dashboard

Dashboard เชิงเล่าเรื่องสำหรับวิชา **Business Idea Creation** (กลุ่มอุตสาหกรรมผลิตภัณฑ์เสริมอาหาร)
MYSUPP คือแพลตฟอร์มวางแผนอาหารเสริมเฉพาะบุคคลด้วย AI จากผลตรวจสุขภาพจริง

> ข้อมูลทั้งหมดเป็นข้อมูลจำลอง (mock data) เพื่อการนำเสนอ

**เปิดดูบนเว็บ:** https://67160358petnapakorn.github.io/mysupp-dashboard/

## เนื้อเรื่อง (พรีเซนต์ 3 นาที)
1. ลูกค้า – ใครคือผู้ใช้และมาจากช่องทางไหน
2. AI ทำงานอย่างไร – จากผลตรวจเลือดถึงสูตรเฉพาะคน และอัตราทานครบ
3. ผลลัพธ์ – สมาชิกเพิ่มขึ้น Churn ลดลง
4. ธุรกิจ – รายได้ ต้นทุน กำไร
5. การเติบโต – Funnel จากผู้สนใจถึงบอกต่อ

## โครงสร้าง
```
index.html     หน้า Dashboard (ไฟล์เดียว เปิดได้ทันที)
data/*.csv     ข้อมูลที่ใช้ (นำเข้า Power BI / Excel ได้)
.nojekyll
```
ข้อมูลที่กราฟใช้อยู่ในตัวแปร `D` ใน `index.html` และมีสำเนาเป็น CSV ใน `data/` หากแก้ตัวเลขให้แก้ทั้งสองที่

## ตารางกรอบ Dashboard
| บท | คำถาม | ตัวชี้วัด | กราฟ |
|---|---|---|---|
| 1 ลูกค้า | ใครคือผู้ใช้ | สัดส่วนกลุ่มเป้าหมาย, ช่องทาง | แท่งแนวนอน |
| 2 AI | ช่วยให้ทำตามแผนได้จริงหรือไม่ | อัตราทานครบ, เวลาออกสูตร | เส้น |
| 3 ผลลัพธ์ | ผู้ใช้อยู่นานและสุขภาพดีขึ้นหรือไม่ | สมาชิก, Churn, ค่าตรวจเลือดที่ดีขึ้น | แท่ง, เส้น |
| 4 ธุรกิจ | คุ้มต้นทุนหรือไม่ | รายได้, ต้นทุน, กำไร | แท่งแนวนอน |
| 5 การเติบโต | หลุดที่ขั้นไหน | Conversion | Funnel |
| สรุป | จะทำอะไรต่อ | 3 การกระทำหลักจากข้อมูล | การ์ดสรุป |
